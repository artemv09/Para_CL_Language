# ParaCL

Сборка, запуск и построение AST одной командой из корня проекта:

```sh
./run.sh
```

Текст программы всегда читается из `program.pcl` в корне проекта.
Редактируйте этот файл и снова запускайте `./run.sh`.
Скрипт сохраняет дерево в `graphviz/program.pcl.dot` и изображение
в `graphviz/program.pcl.svg`; повторный запуск перезаписывает эти файлы.
Скрипт можно вызвать и из другой директории, указав путь к нему.
Для работы нужны CMake, компилятор C++17 и Graphviz (`dot`).
Экспорт показывает структуру AST после синтаксического разбора; семантический
анализ пока не реализован.
